※何を実装したかについては、作業完了後に ReadMe.md に記載すること。

# コーディング規約
- 命名規則・インデント: 一般的なC++の規約に準拠すること。
- コメントアウト: 処理の意図や内容をなるべく細かく具体的に記述すること。

# 実装時の特記事項・禁止事項
- マジックナンバーの使用を禁止する。必ず定数（constexpr等）を使用すること。
- 無駄な処理を何度も繰り返すような、非効率なコーディングをしないこと。

# AIへの指示（厳守事項）
- 回答は短く簡潔にすること。
- 聞かれたこと以外の余計なコードを追加しないこと。
- コードの順番を勝手に変更しないこと。
- 変更箇所にはわかりやすい目印をつけること（ただし特殊な記号は使用しない）。
- コメントアウトに不自然な記号を使用しないこと。
- 提示されたコードを省略して返すのは禁止。
- 「整理して」と指示された場合は、処理内容は一切変更せず、不要なコメントの削除、わかりやすいコメントの追加、インデントの改善のみ行うこと（見やすさのための順番変更は許可する）。
