# プロジェクト概要
- 言語・API: C++、DirectX 12
- ジャンル: 3Dレールシューティング（スプラトゥーンのレール上のミニステージを参考）

# 開発環境
- Visual Studio 2026

# 今後の開発予定（優先順位順）
1. レール移動の基礎ロジック（最優先）
   - プレイヤー（メインカメラ）が制御点間を実際に移動できるようにする
   - 移動時、各Pointに設定されたSpeed値を反映する
   - Position変化（進行方向）に応じてカメラの向きを自動追従させる
2. 的オブジェクトの配置・撃破システム
   - 的オブジェクトをステージ上に配置する
   - 照準（画面中央固定レティクル）と的の当たり判定を実装する
   - 撃破時に的を消去し、簡易的な演出（エフェクト等）を入れる
3. RailEditor：制御点の削除機能
   - ImGui上のリストから制御点を選択し削除できるようにする
   - 削除後、レールカーブの再計算（インデックスのズレ対策含む）を行う
4. （優先度低・後回し）JSONホットリロード機能
   - 実行中にImGuiで変更した値を、そのままファイルへ保存・反映できるようにする

# コーディング規約
- 命名規則・インデント: 一般的なC++の規約に準拠すること。
- コメントアウト: 処理の意図や内容をなるべく細かく具体的に記述すること。

# 実装時の特記事項・禁止事項
- マジックナンバーの使用を禁止する。必ず定数（constexpr等）を使用すること。
- 無駄な処理を何度も繰り返すような、非効率なコーディングをしないこと。

# AIへの指示（厳守事項）
- 回答は短く簡潔にすること。
- 聞かれたこと以外の余計なコードを追加しないこと。
- コードの順番を勝手に変更しないこと。
- 変更箇所にはわかりやすい目印をつけること（ただし特殊な記号は使用しない）。
- コメントアウトに不自然な記号を使用しないこと。
- 提示されたコードを省略して返すのは禁止。
- 「整理して」と指示された場合は、処理内容は一切変更せず、不要なコメントの削除、わかりやすいコメントの追加、インデントの改善のみ行うこと（見やすさのための順番変更は許可する）。
